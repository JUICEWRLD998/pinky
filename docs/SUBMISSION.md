Deadline: 2026-11-14 23:59 UTC. One submission per repository. Mistakes go through https://nearhackathon.com/request-changes.

Needed from the team lead (never guessed or filled by an agent):

- [ ] Project name (2-80 characters)
- [ ] Team lead name (2-80 characters)
- [ ] Contact email
- [ ] Team size: one of `1`, `2 - 4`, `4 - 6`, `6 - 8`, `8+`
- [ ] Tracks: `games`, plus `swarms` only once the league runs
- [ ] NEAR mainnet account for the prize payout
- [ ] Public repository link
- [ ] Public demo post link on X (says built at NEAR HACKATHON, tags @NEARProtocol and #NEARHackathon, has the video)
- [ ] `idea` text, 20 to 2000 characters
- [ ] Consent to the contact notice

Before sending: repository is public, LICENSE present, README steps run from a clean clone, demo URL stays up to 2026-11-25.
