# Pinky

Keep it or break it. A promise game against characters that hold their own money, remember what you did, and pay for their own thinking. Built for NEAR HACKATHON (Games With Real Economies).

Status: work in progress. Phase 1 (rules, core logic, simulation) is in this repo. The contract, app and audit follow.

## Try it (Phase 1)

```
npm test          # conservation, determinism, planted-control tests
npm run sim       # seeded 10,000-round simulation, prints headline numbers
```

Requires Node 24 or newer. No dependencies to install.

The rules are in `docs/RULES.md`.
